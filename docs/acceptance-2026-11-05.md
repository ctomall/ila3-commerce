## 过程中发现并修复的真实缺陷

1. 界面语言未强制 → 全站英文（`OM_FORCE_LOCALE=zh`）
2. 字典含 2 184 个 `\r` → 清洗
3. 种子数据英文（92 字段标签 / 75 选项值）→ 数据迁移 + 代码补丁
4. 仪表盘日期用 `navigator.language` → 改为文档语言
5. 列表加载失败伪装成空 → 错误态（T11b）
6. `og:image` 指向 localhost → `metadataBase`
7. 升级停服 2–7 分钟 → **10.8 秒**
