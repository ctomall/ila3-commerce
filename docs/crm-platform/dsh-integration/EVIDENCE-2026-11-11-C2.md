## 2. 结果

```
POST /api/ai_assistant/chat  → HTTP 200, 9,390 B, 1.77 s
SSE: tool-call  mcp__crm__crm_find_companies  ×2
     tool-result ×1，内容含 error code binding_inactive
     text: TOOL_DENIED_OK
mock: 第 1 轮 hasToolResult=false → 第 2 轮 hasToolResult=true（工具确实被执行并回填）
```

链路：CRM session → chat route（签 run token）→ DSH 子进程（mounted MCP）→ `dsh-crm-mcp` → CRM 桥 → **403 binding_inactive**（fail closed）→ tool_result → 模型收尾。

**为什么 403 是正确结果**：B1 的 `dsh_assistant_bindings` 迁移尚未应用，桥在“找不到 active binding”时必须拒绝，而不是伪造组织级数据。token 中的 `bindingId='unbound'` 是显式占位，永不匹配真实行。
