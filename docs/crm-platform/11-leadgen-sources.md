## 2. 依赖包到底给了什么（已读源码，非猜测）

`@open-mercato/web-research@0.9.0`：

| 能力 | 代码位置 | 结论 |
|---|---|---|
| SSRF 防护 | `node_modules/@open-mercato/web-research/src/net/ssrf.ts`（含 `169.254.0.0/16`、loopback、scheme 白名单） | **有**，抓取前调 `assertPublicUrl` |
| 抓取礼貌延迟 | `.../src/net/client.ts:44,301-311` `politenessMs`（按 host 记 `nextAllowedAt`） | **有**，但默认 `0`，必须配置 |
| 每适配器调用上限 | `.../src/contract/policy.ts` `maxCallsPerHour` | **只有字段**，注释明说“engine 不执行，由宿主计数” |
| 页面上限/并发 | `ContentPolicy.maxPages`、`SearchPolicy.concurrency` | 有 |
| **robots.txt** | 全包 grep `robots` **零命中** | **没有** ← 必须自己补 |

所以「用 web-research 抓取」不等于合规：**robots 检查、host 级礼貌延迟、调用计数**这三件事要我们提供。

## 3. 合规门（每条都有失败处置）

| # | 门 | 判据 | 不满足时 |
|---|---|---|---|
| G1 | robots 允许 | `src/lib/leadgen/robots.ts` 判定 `allowed` | 不入队，记 `robots_blocked` |
| G2 | 有明确 ToS/公开授权 | 人工登记来源白名单 | 不用该来源 |
| G3 | 礼貌延迟 | 每 host ≥ 1s（可配） | 配置未设则不启动任务 |
| G4 | 每来源调用上限 | 宿主计数，达上限停用该适配器 | 停止，不静默降速 |
| G5 | 不碰登录墙/验证码 | 出现即放弃该页 | 记 `gated`，不尝试绕过 |
| G6 | 只取公开商务信息 | 公司名/域名/公开邮箱/职位 | 不抓个人隐私、不抓私人手机 |
| G7 | 证据留痕 | 每字段带来源 URL + 抓取时间 + content hash | 无证据的候选直接 `fail`（见验证层） |

## 4. 已实现的合规组件

`src/lib/leadgen/robots.ts`（10 条测试）：

| 规则 | 行为 |
|---|---|
| 分组与注释 | 按 `User-agent` 分组，忽略注释与空行 |
| 空 Disallow | 视为全允许 |
| agent 精确/包含/通配 | 精确 > 包含 > `*` |
| 最长匹配 | 长规则胜；**同长度 Allow 胜** |
| 通配符与锚 | 支持 `*` 与 `$` |
| 无 robots.txt | 全允许（并留 `reason`） |

**负向对照**：破坏“Allow 胜平局”和“最长匹配” → **4 条变红**；恢复后 10 条全绿。

## 5. 采集流程（与 M5 里程碑对齐）

```
选品/选市场 → 任务创建（额度预留）
  → 来源枚举（官网/名录）
  → 每个 URL：robots 检查 → SSRF 检查 → 礼貌延迟 → 抓取
  → 抽取（公司/域名/公开邮箱/职位）+ 证据（URL/时间/hash）
  → 候选提交（不猜造联系人）
  → 确定性验证（verification.ts）
  → 公司级去重（company_dedupe_key）
  → 人工审核 → 幂等入库
```

## 6. 验收（M5 完成时）

1. 一个产品一个市场，产出 ≥ 20 条候选，每条有 ≥ 1 条证据。
2. `robots_blocked` 计数 > 0 时**确实被拦下**（不是记录后照抓）。
3. 同一公司两条候选 → 去重键相同，只有一条可入库。
4. 无邮箱公司保留、标记不可触达；MX 不改变结论。
5. 整个流程零真实外发。
