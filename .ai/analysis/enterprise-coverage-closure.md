## Direct gap sweep

`scripts/enterprise-direct-page-audit.mjs` renders exactly the routes the matrix
lists as gaps; `[params]` become a normal sentinel UUID. 74 routes: 69 rendered,
5 handled a missing record as a readable not-found state, 0 crashes, 0 uncaught
page errors. Four narrow-width overflows were recorded; two were real and are
fixed in 0.2.9 (below), two did not reproduce on an isolated re-measure:

- `/backend/checkout/pay-links/create` and `/backend/checkout/templates/create`:
  the MDXEditor toolbar group paints past 390px, but `documentElement.scrollWidth`
  stayed 390 in an isolated re-measure, so the document does not scroll. Recorded
  as a false positive of the sweep, not fixed.

## 0.2.9 fix: grid cards with wide tables

`/backend/prototype/candidates` (843px document) and `/backend/prototype/drafts`
(668px) at a 390px viewport. Two causes measured in the DOM:

1. the card is a grid item whose automatic minimum width is its content's
   min-content size, so a `min-w-[640px]` table inside forced the single-column
   track to 827px;
2. the table had no local scroll port, so it widened the page instead of
   scrolling inside its card.

Fix in `src/app/globals.css` at `<48rem`: `#main-content .grid > * { min-width: 0 }`
plus `#main-content div:has(> table) { max-width: 100%; overflow-x: auto;
position: relative }`. Measured after the fix via the same probe: document 390,
table wrapper 346 wide with 815/640 scrollWidth and `overflow-x: auto`. A
Playwright case covers both routes (document ≤ viewport, local scroll present).

## Observation: `/docs/api`

The start page links to `/docs/api` publicly, and an anonymous server response is
the explorer HTML. In a browser, a fresh 1440 context lands on
`/login?redirect=/docs/api`, one 1440 attempt had its navigation interrupted, and
a 390 run rendered the explorer. Access is inconsistent for anonymous callers;
the OpenAPI definition itself is public at `/api/docs/openapi`. Not changed —
this needs a product decision (public docs vs auth-gated shell), so it is tracked
as an observation, not silently patched.
